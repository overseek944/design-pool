# Routes

A route is a **saved query**, not a saved composition. It names a region of
axis-space and the tags that matter there — it never lists a fixed set of
primitives, because that would be storing someone's layout.

```md
## engineered-dark
Technical product surfaces. Still, sparse, heavy, refined.
    bin/pool query --energy 1-3 --density 1-3 --weight 3-5 --finish 4-5
    bin/pool query --neutral --tags correctness,accessibility
Contrast axis to consider pushing: energy (one kinetic element against stillness).
```

Routes are starting points that still resolve through the query engine, so they
stay correct as the pool grows. Add one when you find yourself typing the same
query twice. Never paste primitive ids into a route.
